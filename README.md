# こみゃくのうみ

「こみゃくのうみ」は、2025年日本国際博覧会（大阪・関西万博）の「EXPO 2025 Design System」からインスパイアされた、非公式のジェネレーティブ・サウンド・ファンアート（二次創作）です。
海から生まれ、出会い、響き合う「こみゃく」たちの世界。

---

## 特徴

### ジェネレーティブ・アート
- こみゃくたちが画面上を自律的に漂う、クラゲのような動き
- 個体ごとに異なる誕生・成長・結合（Join）・寿命のライフサイクル
- 一定確率で発生する変異個体「ウニ」
- 時折出現する大きな個体「ヌシ」

### ジェネレーティブ・ミュージック
- Web Audio APIによるリアルタイム音楽生成
- 個体の色ごとに異なる音源（ピアノ・マリンバ・ベース）
- こみゃく同士が結合（Join）すると、和声を伴った特別なフレーズを生成
- 巨大な水槽の中にいるようなリバーブ（残響）表現
- ヌシ出現時は専用のコード進行による荘厳な和音演奏。和音の音圧感に応じて瞳の大きさがゆっくり変化する
- 時刻に応じて曲の調性（メジャー / マイナー）が自動で切り替わる「TIME OF DAY / SCALE」機能

### PWA対応
- ホーム画面に追加してアプリのように起動可能（iOS / Android）
- オフラインでも動作（Service Worker）

### カスタマイズ
- マスターボリューム調整
- テンポ切り替え（BPM 120 / 60）
- 時間帯・調性の切り替え（AUTO / LIGHT / DARK）。DARK時は画面の背景も暗く変化する
- こみゃくの出現数調整（少なめ / 自動 / 多め）
- 背景写真のアップロード（HDR画像のトーンマッピング対応）

## 使い方

1. `index.html` をブラウザで開く
2. 「はじめる」をタップして開始
3. 画面下部のドックから再生/一時停止・設定を操作

設定メニューでは以下の項目を調整できます。

| 項目 | 内容 |
|---|---|
| MASTER VOLUME | 全体の音量 |
| TEMPO | 曲のテンポ（1/1 = BPM120、1/2 = BPM60） |
| TIME OF DAY / SCALE | 曲の調性（AUTO=時刻に応じて自動 / LIGHT=長調 / DARK=短調・暗い背景） |
| Co-MYAKU | 画面に出現する個体数（FEW / AUTO / MANY） |
| BACKGROUND PHOTO | 背景画像のアップロード・リセット |

## 技術構成

- フロントエンド: 素のHTML / CSS / JavaScript（フレームワーク不使用）
- 描画: Canvas 2D API
- 音響: Web Audio API（オシレーター・コンボリューションリバーブ・フィルター等）
- PWA: Web App Manifest・Service Worker（すべて単一ファイルにインライン化）

単一の `index.html` として完結しており、追加のビルドステップやサーバーサイド処理は不要です。
